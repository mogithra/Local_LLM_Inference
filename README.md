# Week 8 - Local LLM Inference

## Objective

The objective of this project is to run Large Language Models locally using Ollama and generate responses using Python.

## Tools Used

- Python
- Ollama
- Llama 3.2
- Pandas
- Jupyter Notebook

## Features

- Install and configure Ollama
- Download and run a local LLM
- Generate responses using different prompts
- Compare generated responses
- Save conversation history
- Prepare the environment for chatbot development

## Model Used

Llama 3.2

## Conclusion

The project demonstrates how Large Language Models can be executed locally using Ollama. Local inference provides privacy, offline access, and flexibility for developing future chatbot applications.
